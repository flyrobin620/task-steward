# 契约与数据兼容

修改任何其他代码或已存数据依赖的契约之前，读本文：账本事件、配置文件、数据目录布局、任务书与报告
格式、MCP 工具、CLI 的机器可读输出与退出码、hooks 的输入输出、插件接口。设计文档中已规定的版本规则
优先于本文。

## 契约与各自的规则

| 契约 | 规则 | 设计来源 |
| --- | --- | --- |
| 账本事件（`ledger/`） | 只追加，不改写、不删除。事件类型与字段只增不删、不改含义；新代码必须能归约所有已经写入过的事件类型 | DN002 §7、DN007 |
| 检查点与 SQLite 投影 | 派生数据，可以重建。归约规则或表结构变化时提升写入检查点的版本号，旧检查点作废，需要显式 `tsw ledger rebuild` | DN007 |
| 配置（`config/task-steward.json`） | 带 `version`，当前为 1，未知字段报错。新增字段必须有保持旧行为的默认值；不兼容变更提升 `version`，并提供迁移命令 | DN003 |
| 数据目录（`tsw-home.json`） | 记录数据目录版本与产品兼容版本；不兼容的布局变化提升版本并提供迁移命令 | DN006 §9 |
| 插件接口 | `plugin_api` 为整数，不兼容变更加 1；核心拒绝加载版本不匹配的插件 | DN006 §5 |
| MCP 工具、CLI 输出与退出码 | 只增不删：新增工具、命令、选项和可选字段；不删除、不改名、不改类型或含义，不把可选改为必填 | DN001 §7 |
| hooks 输入输出 | 遵循宿主（Claude Code）的 hooks 契约；读取 payload 时忽略未知字段 | DN001 §7.3 |
| 任务书与报告（`todo/`、`runs/`） | 已有文件永远可读；新增内容不改变旧文件的解释 | DN001、DN007 |

## 规则

- 读取方忽略不认识的可选字段，但忽略不能跳过身份校验、已知字段的校验或大小限制。
- 账本中出现当前版本不认识的事件类型时，不能静默忽略（会让归约结果错误）：按 DN007 §3.3 拒绝写入与
  依赖投影的读取，并报告需要升级。
- 保留不再使用的字段，在 schema 或注释中标记弃用，直到有决定删除它。

## 测试

- 保留各版本实际写出的样本：账本、配置、数据目录（`tests/fixtures/compat/<版本>/`）。新代码必须能读取
  它们，并把样本账本归约到记录在案的投影结果。
- 新增字段时，测试缺少该字段的旧样本仍按旧行为工作。

## 必须删除或不兼容变更时

这是设计变更：先在设计文档写明受影响的读取方、迁移命令、执行顺序与回退方式，经用户确认并记录到
[../decisions/README.md](../decisions/README.md)，再实现所需的最小版本机制。
