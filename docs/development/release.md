# 版本与发布

修改版本号、打包方式、插件清单或发布流程之前，读本文。这些改动合并前须用户明确确认。

## 当前状态

v1 开发期间不发布：没有版本标签、没有发布流水线，也不发布到任何包仓库。使用方式是从本仓库的检出目录
安装 Claude Code 插件。

开发期间 `plugin/.claude-plugin/plugin.json` 与市场条目都不写 `version`：Claude Code 只在计算出的版本
变化时替换已安装的插件副本，固定的版本字符串会让副本永远停在第一次安装时；不写时版本取提交。产品更新后
运行 `tsw host render`（它会运行 `claude plugin update`）并重启会话（CC006 §2）。

## 发布规则（第一次发布前确定细节）

- 版本号只有一个来源（`tsw/__init__.py` 的 `__version__`），使用 PEP 440 格式，例如 `0.1.0`。
- 发布从 `main` 上的提交打标签 `vX.Y.Z`；同一版本只发布一次，修复用新版本。
- 打标签前，全部 live 场景在该提交上运行通过，证据写入发布记录。
- 发布记录写明版本、来源提交、live 场景的运行结果，以及已知未验证项。
- 发布完成的含义：在干净的 Claude 配置中从该标签安装插件，`host-e2e` 冒烟场景通过。
