## 规则

- 每份记录写明背景、决定与后果。这里只记录已确认的决定；提议留在设计文档。
- 文件名为 `NNNN-<slug>.md`，按顺序编号，不重新编号，不复用编号。
- 不通过编辑已接受的决定来推翻它：新增一份取代它的记录，把旧记录的状态改为“已被 NNNN 取代”。
- 由决定推出的规则写在专题文档里，记录中链接过去。
- 设计文档（DN001–DN007）中经用户确认的设计本身也是决定，不在这里重复；这里记录设计之外的决定。
